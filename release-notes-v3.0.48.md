# GibVPN Smart v3.0.48

## 🤖 Режим агента (control-API)

Приложение поднимает локальный API на `127.0.0.1:7781` — ИИ-агент (через мост gibvpn-mcp) может:

- `GET /status` — состояние: подключён ли VPN, режим, WARP, TUN, активный сервер
- `GET /servers` — список серверов активной подписки
- `POST /connect {"server": "..."}` — подключить выбранный сервер
- `POST /disconnect` — отключить
- `POST /mode/ai` — запустить подбор «ИИ»
- `POST /warp {"enabled": true/false}` — переключить WARP

API слушает только localhost и не имеет доступа из сети.

## 🎯 Двухступенчатая проверка режима «ИИ»

Больше ложных «рабочих» серверов:

1. **Ступень 1 (быстрая):** Flow-фильтр — как раньше, батчами, отсекает региональные заглушки.
2. **Ступень 2 (экзамен):** каждый финалист поднимает изолированный тестовый канал, egress OmniRoute временно направляется на него, и сервер обязан дать **реальный ответ модели Antigravity 2 раза подряд** (с замером латентности). Подключается только подтверждённый сервер.

Без настроенного OmniRoute режим деградирует к прежнему поведению (только Flow).
