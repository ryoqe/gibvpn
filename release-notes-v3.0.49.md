# GibVPN Smart v3.0.49

## 🩺 Чистка «мёртвых» Wintun-адаптеров

Упавший или жёстко завершённый sing-box оставлял адаптер `gibvpn-*`, который держал IPv4-адрес туннеля. Новый запуск падал с `set ipv4 address: The object already exists`, туннель оставался полумёртвым, а DNS и маршруты прошлого запуска висели — вплоть до потери сети.

Теперь перед каждым спавном TUN GibVPN находит через `Get-NetAdapter` остаточные адаптеры `gibvpn-*`, удаляет устройство через `pnputil /remove-device` и отключает адаптер. Остатки прошлых запусков больше не мешают подключению и не ломают сеть Windows.

## 🌐 Доменные адреса серверов в режиме «Полный VPN»

Если в подписке адрес сервера задан доменом, а не IP, TUN-режим раньше падал целиком: маршрутам туннеля нужен IP, а код ожидал только числовой адрес.

Теперь доменное имя резолвится системным DNS (IPv4), и подключение в TUN-режиме работает с такими подписками. Если адрес определить не удалось, приложение по-прежнему сообщает об ошибке, не трогая маршруты.
