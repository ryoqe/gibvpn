# Roadmap улучшений GibVPN Smart v3

> Практичный план развития, отсортированный по эффекту / трудозатратам.
> Актуализировано: 17.07.2026 (после спринта 4).

---

## 1. Фундамент

- [x] Исправить сохранение настроек, подписок и оформления после перезапуска в собранном `.exe`.
- [x] Не паковать в `.exe` файлы кеша подписок (`decoded_sub*.txt`) — исключены из spec.
- [x] Проверять доступность папки `APP_DIR` при старте (fallback на `%LOCALAPPDATA%\GibVPN`).
- [x] Обработка ошибок при работе с реестром автозапуска.
- [x] Устойчивость подписок к кодировкам: UTF-8/UTF-16 (BOM и без), base64(UTF-16).
- [x] Атомарная запись `app_settings.json` (`.tmp` + `os.replace`).
- [x] Сборка без остановки работающего VPN: `build.py` гасит только приложение (xray продолжает работать) и пересобирает `dist/` на месте.

---

## 2. Сделано (спринты 1–3)

### UX интерфейса
- [x] Иконка в системном трее + сворачивание в трей при закрытии окна.
- [x] Горячие клавиши: `Ctrl+R` — обновить подписку, `Ctrl+S` — настройки, `Space` — Старт/Стоп.
- [x] Кнопки «Скопировать лог» / «Очистить лог».
- [x] Ротация лога: `gibvpn_error.log` ограничен 5 МБ (хранится `.old`).
- [x] Обновление подписок в фоне (UI не виснет), busy-индикатор.
- [x] Палитра Apple HIG по дизайн-гайду (системные цвета, zebra-таблицы, статусные цвета).

### Подписки
- [x] Валидация URL подписки перед сохранением (формат http/https + хост).
- [x] Кнопка «Обновить все подписки» + дата/время последнего обновления.
- [x] Импорт / экспорт списка подписок в JSON.

### Серверы и подключение
- [x] Названия серверов из подписки (remark) в списке и в статусе соединения.
- [x] Поиск (название/адрес/протокол/статус) + быстрый фильтр по статусу.
- [x] Сортировка по столбцам (пинг — числовая).
- [x] Массовое изменение статуса (мультивыбор Ctrl/Shift + контекстное меню).
- [x] Избранное двойным кликом.
- [x] История пинга: последний результат хранится в настройках и виден сразу (с датой измерения).
- [x] Статус соединения: имя сервера, пинг, аптайм сессии.

### Безопасность / предсказуемость
- [x] Single-instance через `QLockFile`.
- [x] Завершение только своих xray-процессов (реестр по PID; `taskkill /IM` удалён).
- [x] При выходе корректно завершать `xray.exe`.
