# GibVPN Smart v3.0.50 — 15 ноября 2026

## Безопасность локального control-API

- API на `127.0.0.1:7781` принимает запросы только с `Host: 127.0.0.1/localhost` и отклоняет любой запрос с заголовком `Origin`. Это блокирует CSRF со стороны открытых в браузере страниц и попытки DNS-rebinding.
- Порт и случайный токен на запуск публикуются в `%APPDATA%\GibVPN\agent_api.json`; токен передаётся заголовком `X-GibVPN-Token`. Обязательный режим включается через `GIBVPN_AGENT_REQUIRE_TOKEN=1` после обновления MCP-клиента.
- Ошибки запуска API пишутся в `session.log` вместо невидимой консоли.

## ИИ-режим

- Если OmniRoute недоступен или E2E не подтвердил модель, приложение больше не оставляет пользователя без VPN: подключается лучший сервер, прошедший Flow-проверку, с явным предупреждением в логе.
- Egress провайдера Antigravity сохраняется на диск перед E2E и восстанавливается при следующем запуске после аварийного завершения. Исправлено состояние, когда предыдущий egress был пустым (`None`) и не восстанавливался.
- Пути и адрес OmniRoute больше не содержат имя пользователя: используются `~/jarvis` и переменные `GIBVPN_OMNI_*`.

## Исправления

- Пробел в поле поиска по логу больше не включает и не выключает VPN.
- Аварийное восстановление интернета возвращает прежний системный прокси из снапшота, а не удаляет настройки пользователя.
- Проверка конфликтующих VPN-адаптеров исключает собственные адаптеры `gibvpn-*` (прежнее имя `gibvpn-tun` устарело).
- Статистика трафика опрашивается раз в 5 секунд вместо 3.
- Удалён неиспользуемый код, четыре обёртки `smart_start_*` сведены к одному обработчику ошибок.
- `build.py` проверяет совпадение `appcore.CURRENT_APP_VERSION`, `version.txt` и git-тега до сборки.
- Тесты и release notes возвращены в репозиторий; live-скрипты перенесены в `tools/`.
