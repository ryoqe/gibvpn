# GibVPN Smart v3.0

[![Release](https://img.shields.io/github/v/release/ryoqe/gibvpn?style=for-the-badge&color=007AFF)](https://github.com/ryoqe/gibvpn/releases/latest)
[![Download](https://img.shields.io/badge/Скачать-Windows%20x64-34C759?style=for-the-badge&logo=windows)](https://github.com/ryoqe/gibvpn/releases/latest)
[![Python](https://img.shields.io/badge/PyQt6-3.10+-38BDF8?style=for-the-badge&logo=python)](https://www.python.org/)
[![License](https://img.shields.io/badge/Лицензия-MIT-orange?style=for-the-badge)](LICENSE)

Современный, быстрый и удобный десктопный VPN-клиент для Windows на базе **PyQt6** и **Xray-core** с поддержкой **Zapret DPI bypass**, замером реальной скорости и объединённым режимом всех подписок.

В 3.0.47 ручное подключение больше не меняет избранное; двойной щелчок в списке
подключает выбранный сервер. Номер запущенной версии виден в окне и трее.
Обычный «Старт» может восстановить последний рабочий сервер без полного перебора;
нажатие кнопок режимов и «ИИ» сохраняет явный подбор. При недоступной сети/DNS
маршруты TUN не устанавливаются. После подключения больше не запускается ненужная
массовая фоновая проверка остальных серверов. Сведения о запуске сохраняются в
`%APPDATA%\GibVPN\runtime.json`, журнал подключения — в `session.log`.

В 3.0.45 загрузки Steam Cloud с хранилищ Amazon направляются через выбранный VPN,
даже если Steam добавлен в прямые приложения. Магазин, вход и остальные соединения
Steam сохраняют прямой маршрут. Это исправляет подтверждённые таймауты Tavern Keeper.

В 3.0.46 добавлен выключенный по умолчанию режим **«THE FINALS: уменьшить задержку»**
в настройках. В режиме «Полный VPN» он направляет служебные TCP-подключения игры
через выбранный VPN без WARP, а UDP игры — напрямую. Настройка применяется только
при следующем подключении VPN, поэтому её переключение не прерывает текущий матч.
Если игровые UDP-соединения тоже заблокированы провайдером, этот режим не поможет:
в таком случае выключите его перед следующим подключением. На текущей игровой
сессии изменение маршрута не проверялось.

## 🔥 Главные возможности

- **⚡ 4 Режима автовыбора серверов**:
  - **МИН**: подключается к серверу с наименьшей задержкой (пингом).
  - **МАКС**: выбирает сервер с наибольшим количеством доступных проверочных сайтов (YouTube, Google, Telegram и др.).
  - **СКОРОСТЬ**: замеряет скорость реального скачивания (МБ/с) и выбирает самый быстрый сервер.
  - **ИИ**: ищет сервер по доступу к `https://flow.google.com/`, отклоняет региональную заглушку и продолжает поиск по всему незаблокированному списку. С WARP проверяет последовательно: несколько WireGuard-туннелей с одним профилем могут мешать друг другу. Без WARP проверяет партиями по четыре. Сначала пробует последний удачный сервер, затем серверы с пометкой Gemini и избранные. Пометка Gemini не заменяет проверку.
- **Подключение вручную**: «Подключиться» в списке запускает именно выбранный сервер сразу, без пинга, замера скорости или автовыбора. Этот выбор сохраняется до нажатия кнопки другого режима.
- **WARP ВКЛ / ВЫКЛ** рядом с «ИИ»: включает или отключает Cloudflare WARP для ИИ-доменов и всего Antigravity. Без WARP эти запросы идут через выбранный VPN-сервер. Переключение при подключённом VPN перезапускает его на том же сервере. Выбор сохраняется. Поиск «ИИ» с включённым WARP требует импортированный профиль.
- **🛡 Обход блокировок DPI (Zapret / WinWS)**:
  - Автоматическое исключение IP-адреса VPN-сервера (`--outbound-out-exclude-ip`), благодаря чему Zapret не ломает VPN-туннель.
- **📊 Замер реальной скорости (Speedtest)**:
  - Проверка пропускной способности серверов (в МБ/с и КБ/с) через изолированные тестовые соксы.
- **★ Объединённый режим «Все подписки»**:
  - Просмотр, замер и единое управление статусами (Избранное / Заблокирован) для серверов из всех подписок сразу.
- **📝 Встроенный редактор конфигураций**:
  - Открытие и редактирование `warp_domains.txt`, `direct_domains.txt`, `direct_apps.txt` и `config.json` прямо внутри приложения.
- **💾 Полный Экспорт / Импорт настроек**:
  - Сохранение и восстановление всех подписок, доменов, приложений и графических настроек в единый `.json` файл.
- **🔄 Автообновления через GitHub**:
  - Автоматическая проверка и загрузка новых релизов с обязательной проверкой SHA-256 от GitHub.
- **🌐 Полный VPN (TUN)**:
  - Весь TCP/UDP-трафик и DNS направляются через виртуальный адаптер; для включения нужны права администратора.
- **🔐 Личный WARP-профиль**:
  - Импортируйте свой `wgcf-profile.conf` в настройках. Ключ не включается в сборки или репозиторий.
- **🌐 Поддерживаемые протоколы**:
  - `VLESS` (включая REALITY, XHTTP, gRPC, WebSocket, TCP), `VMess`, `Trojan`, `Shadowsocks`.
- **⚙️ Актуальные сетевые ядра**:
  - Xray-core 26.7.28 и sing-box 1.13.14 встроены в автономный EXE и обновляются вместе с приложением.

## 🛠 Запуск из исходного кода (Для разработчиков)

Если вы хотите вносить изменения в исходный код или запустить проект локально:

```bat
# 1. Клонировать репозиторий
git clone https://github.com/ryoqe/gibvpn.git
cd gibvpn

# 2. Создать виртуальное окружение и установить зависимости
python -m venv venv
venv\Scripts\pip install PyQt6 requests pyinstaller

# 3. Запустить приложение
run_gui.bat
```

### 🧪 Запуск тестов:
```bat
venv\Scripts\python tests/run_isolated.py
```

### 📦 Сборка собственного .exe:
```bat
build.bat
```
Скрипт оставит запущенное приложение и VPN работать, проверит SHA-256 официального Xray и создаст один файл:
`dist\GibVPN_Smart_v3.exe`.
Если этот файл сейчас запущен, сборка остановится: используйте другую папку через `PyInstaller --distpath`. Тесты используют отдельные настройки и не записывают изменения в реестр Windows.

Проверка Flow подтверждает сетевой доступ к обычной странице без региональной заглушки. Генерация после входа также зависит от аккаунта Google; автоматический подбор не входит в аккаунт пользователя.

Если Gemini открывается, а Flow после входа показывает региональную заглушку, запустите `FLOW_WARP_CHROME.cmd`: он откроет отдельный профиль Chrome, полностью направив его веб-трафик через текущий WARP-прокси. Войдите в Google именно в этом окне. Этот способ подтвердил доступ к рабочему Flow у пользователя; предварительная HTTP-проверка до входа такого подтверждения не даёт. Скрипт требует установленный Chrome и PowerShell 7 и сохраняет текущий VPN работающим.

## 🤖 Локальный control-API (для MCP/агента)

Приложение слушает только `127.0.0.1:7781`. Запросы с чужим `Host` или с заголовком `Origin` отклоняются, поэтому веб-страница не может управлять VPN через браузер. Токен и порт публикуются в `%APPDATA%\GibVPN\agent_api.json` и передаются заголовком `X-GibVPN-Token` (необязательно). Обязательным токен становится при `GIBVPN_AGENT_REQUIRE_TOKEN=1`; включайте это только вместе с обновлённым MCP-клиентом.

Интеграция с OmniRoute настраивается переменными окружения: `GIBVPN_OMNI_DIR`, `GIBVPN_OMNI_BASE`, `GIBVPN_OMNI_MODEL`, `GIBVPN_OMNI_KEY_PATH`, `GIBVPN_OMNI_AUTH_PATH`. По умолчанию используется `~/jarvis` и `http://127.0.0.1:20128`.
